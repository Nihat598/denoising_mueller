# Classical denoising on the 2026-10-15 measurement — report (22 Oct 2026)

What was done, what the results say, where the files are, and how to reproduce everything on your PC.
All numbers below come from the files in `results/2026-10-15_measurement/` (in the GitHub repo).

---

## 1. Short version

- **The pipeline works on real calibrated data.** The Mueller matrices of the reference samples are what physics expects
  (air → identity, polarizer → ideal polarizer, quarter-wave plate passed twice → 180° retarder).
- **On the only tissue sample (finger, in vivo skin), denoising a single frame beats averaging 8 frames.**
  Best: NLM at the intensity level, error 0.017 vs 0.033 for the 8-frame average and 0.094 for the raw frame.
- **On the two cards (plastic card 90°, Meadowlark card), no filter beats 8-frame averaging.** The best filters
  (BM3D / TV / wavelet at the MM level) are about as good as averaging 3–4 frames.
- **Intensity level vs MM level depends on the sample.** Finger: intensity level wins for NLM and BM3D.
  Cards: MM level wins for nearly every filter. Gaussian is identical at both levels (expected: a linear filter
  commutes with the per-pixel MM reconstruction when the calibration varies slowly).
- **Noise biases the polarimetric maps, and MM-level filtering removes most of that bias** on samples whose true
  value is known (e.g. diattenuation of air: 0.066 for one raw frame, 0.045 for an 8-frame average, 0.025 for NLM at
  the MM level; true value 0).
- **Speed (one 512×608 image, 2 CPU cores):** Gaussian, median, NLM, wavelet 0.2–1.3 s; TV ~4.4 s; BM3D
  ~155 s, similar at both levels. MM reconstruction + Lu-Chipman maps add ~2.9 s (see section 6).
- **Biggest limitation:** only one usable tissue acquisition. The calf brain measurement is needed before any claim
  about tissue in general.

## 3. Method (what the scripts do)

For every acquisition, every filter, and both levels, the input and the reference are the same:

- **Input:** frame 1 only (one single noisy measurement).
- **Reference ("best available truth"):** mean of frames 9–16. Disjoint from the input, so the input noise and the
  reference noise are independent.
- **Baselines:** frame 1 with no denoising, and plain averages of frames 1–2, 1–4, 1–8.
- **Intensity level:** variance-stabilizing transform (Anscombe, noise model `var = a·I + b` fitted on the reference
  frames) → filter the 16 raw intensity images → inverse transform → Mueller matrix (M = A⁻¹ I W⁻¹, dark subtracted)
  → Lu-Chipman maps.
- **MM level:** Mueller matrix of frame 1 → filter the 16 (unnormalized) matrix elements → normalize by m11 → maps.
- **Filters:** median, Gaussian, NLM, wavelet, TV, BM3D (CPU implementations: SciPy, scikit-image, PyWavelets, bm3d).

**Tuning.** Each filter has one strength knob (Gaussian sigma, median size, NLM h, wavelet/BM3D scale, TV weight).
On the tuning sample only (plastic card 0°), 3–5 values were tried per filter and per level, and the one with the
lowest error was kept. Those values were then frozen and applied to the test samples. Tuning and testing on different
samples keeps the test scores honest.

| Filter | Intensity level | MM level |
|---|---|---|
| Gaussian | sigma 0.5 | sigma 0.5 |
| Median | 3×3 | 3×3 |
| NLM | h 1.0 | h 0.6 |
| Wavelet | scale 1.0 | scale 1.0 |
| TV | weight 0.5 | weight 0.5 |
| BM3D | scale 1.5 | scale 0.75 |

Note: Gaussian chose the smallest value tried (0.5). The best value may be even lower; it should be extended down
(e.g. 0.3) in the next sweep.

**Main score: `nM_RMSE_corr`.** RMS error of the 15 normalized Mueller-matrix elements against the reference,
**corrected for the reference's own noise**: an 8-frame reference still contains noise, which adds the same amount to
every method's error and hides differences between good methods. The script measures that reference noise (from the
difference between two halves of the reference frames) and subtracts it. On synthetic data with a known truth this
correction matched the true error within 0.0002.

**Why the map scores (linR_RMSE, azimuth_MAE, totP_RMSE) are not the main score.** Retardance, diattenuation and
depolarization are nonlinear functions of the matrix, and noise biases them (section 5). On the finger, the signal is
weak and even the 8-frame reference is visibly biased (retardance too high, depolarization too low, azimuth pure noise
because the retardance is small). A denoised map can then be *closer to the truth* but *further from the reference*.
So map-level errors against this reference are not reliable for low-signal tissue; use them with care and look at the
figures.

Score = `nM_RMSE_corr` (lower is better). Raw single frame, no denoising: finger 0.094, card 90° 0.051,
Meadowlark 0.064.

|---|---|---|---|---|---|
| average of 8 frames | — | 0.033 | **0.017** | **0.021** | **0.024** |
| wavelet | MM | 0.018 | 0.033 | 0.035 | 0.029 |
| BM3D | MM | 0.027 | 0.031 | 0.029 | 0.029 |
| NLM | intensity | **0.017** | 0.042 | 0.036 | 0.032 |
| NLM | MM | 0.021 | 0.040 | 0.036 | 0.032 |
| TV | MM | 0.033 | 0.032 | 0.031 | 0.032 |
| average of 4 frames | — | 0.047 | 0.025 | 0.031 | 0.034 |
| BM3D | intensity | 0.020 | 0.045 | 0.039 | 0.035 |
| TV | intensity | 0.033 | 0.034 | 0.043 | 0.037 |
| wavelet | intensity | 0.025 | 0.044 | 0.051 | 0.040 |
| median | MM | 0.040 | 0.048 | 0.043 | 0.044 |
| Gaussian | MM | 0.061 | 0.037 | 0.043 | 0.047 |
| Gaussian | intensity | 0.061 | 0.037 | 0.043 | 0.047 |
| average of 2 frames | — | 0.066 | 0.035 | 0.045 | 0.049 |
| median | intensity | 0.047 | 0.053 | 0.051 | 0.050 |

How to read it:

1. **Finger:** six filter/level combinations beat the 8-frame average (NLM-intensity, wavelet-MM, BM3D-intensity,
   NLM-MM, wavelet-intensity, BM3D-MM). Single-frame denoising is a real alternative to averaging here.
2. **Cards:** every filter is worse than 8-frame averaging; the best are close to 3–4-frame averaging. The cards have
   a fine, pixel-scale grain; spatial filters cannot separate that grain from noise as well as temporal averaging can.
   The finger's structures (skin ridges) are larger than the noise grain, which is the easy case for spatial filters.
3. **Level:** on the finger the intensity level is better for NLM and BM3D (and the MM level for wavelet); on the
   cards the MM level is better for almost every filter. There is no single winner level; it depends on the sample
   and the filter. The brain data will show which case applies to tissue.
4. **Gaussian:** identical at both levels on all samples (to 3 decimals), as predicted by theory.

Figures: `results/2026-10-15_measurement/figures/<acquisition>__<method>.png`. Columns: input (frame 1), filter at
the intensity level, filter at the MM level, reference. Rows: depolarization, linear retardance, azimuth,
diattenuation. In the finger figures you can see the reference bias described in section 3 (the denoised retardance
is lower and smoother than the reference).

## 5. Bias check on uniform samples (known true values)

Noise does two things to a map: it **scatters** values (grainy map) and it **biases** the median. Diattenuation, for
example, is the length of a vector, so noise can only make it larger. Retardance near 180° folds back below 180°.
On uniform samples we know what the answer should be, so we can measure the bias directly (central ROI, 256×304 px).

**Diattenuation (median; true value 0 for air, metal, QWP):**

| | Air | Metal plate | QWP 0° | QWP 90° |
|---|---|---|---|---|
| raw frame 1 | 0.066 | 0.067 | 0.108 | 0.110 |
| average of 8 | 0.045 | 0.045 | 0.097 | 0.095 |
| NLM, MM level | **0.025** | **0.037** | **0.085** | **0.072** |
| wavelet, MM level | 0.027 | 0.031 | 0.089 | 0.077 |
| TV, MM level | 0.033 | 0.034 | 0.087 | 0.075 |
| NLM, intensity level | 0.058 | 0.058 | 0.108 | 0.102 |

**Retardance of the QWP (double pass, true value 180°):**

| | QWP 0° median (spread IQR) | QWP 90° median (IQR) |
|---|---|---|
| raw frame 1 | 176.3° (2.9°) | 174.9° (4.1°) |
| average of 8 | 177.2° (2.2°) | 175.3° (2.7°) |
| NLM, MM level | **178.0° (1.1°)** | **175.5° (1.3°)** |
| TV, MM level | 177.9° (1.4°) | 175.4° (1.8°) |

How to read it:

- **MM-level filters remove more of the noise bias than the intensity-level filters**, on every uniform sample and
  for every filter except Gaussian (identical at both levels), and reduce the spread of the maps (NLM at the MM level
  by half or more). With the tuned (fairly light) parameters, intensity-level NLM/wavelet/BM3D barely
  change these maps.
- MM-level filters reduce the diattenuation bias *below* the 8-frame average. Part of the remaining 0.025–0.045 may be
  real (a small residual calibration error), so "true 0" is only approximately known.
- Depolarization medians are close to the true value for all methods (no strong bias), only the spread changes.
- The QWP retardance stays a few degrees below 180° for every method: that part is a property of the plate/system,
  not noise.
- Full table: `results/2026-10-15_measurement/reference_samples/metrics.csv` (one row per sample × method × level;
  columns `*_median`, `*_IQR`, `*_bias`, `nM_RMS_vs_ref`).
- `nM_RMS_vs_ref` (element error vs the 16-frame reference) gets *worse* with some filters on these samples. That is
  the fine static texture of the imaged surfaces (section 7): it is in the reference, and smoothing removes it.

## 6. Run time

One 512×608 frame (finger), 2-core cloud CPU, nothing else running. Seconds.

| Method | Intensity: filter only | Intensity: frame → maps | MM: filter only | MM: frame → maps |
|---|---|---|---|---|
| no denoising | — | 2.9 | — | 2.9 |
| Gaussian | 0.2 | 3.1 | 0.2 | 3.3 |
| median | 0.6 | 3.7 | 0.8 | 3.9 |
| NLM | 1.1 | 4.3 | 1.3 | 4.1 |
| wavelet | 1.1 | 4.6 | 0.5 | 3.6 |
| TV | 4.3 | 7.4 | 4.4 | 7.0 |
| BM3D | 152.8 | 155.8 | 159.8 | 162.6 |

About 2.9 s of every "frame → maps" time is the MM reconstruction + Lu-Chipman decomposition, the same for all
methods. Except for BM3D, the filters cost about as much as, or less than, computing the maps themselves.

- `time_denoise_s` = the filter only (for the intensity level, including the forward/inverse Anscombe transform).
- `time_pipeline_s` = one raw frame → final maps (filter + MM reconstruction + Lu-Chipman decomposition). This is the
  number to compare with deep-learning methods, which also need the MM reconstruction afterwards.
- Measured on a 2-core cloud machine with nothing else running. **For the paper, re-run on the DGX Spark** (classical
  methods on its CPU, PDDN on its GPU) and state the hardware for each (commands in section 9).
- The test run (`test/metrics.csv`) also contains times, but two jobs were sharing the 2 cores then, so those BM3D
  times (~300 s) are about 2× too high. Use the numbers above.

## 7. Other findings and caveats

- **Reflection geometry:** a quarter-wave plate gives ~177° retardance because light crosses it twice. Expected, and
  `check_waveplate.py --retardance 180` reports it correctly.
- **Noise level:** about 0.10–0.24 × counts (variance), 3–7× the May 2026 data (digital gain 2). Skin signal is weak
  (13–17 counts out of 255), so single frames are very noisy.
- **Static fine texture:** even after averaging 16 frames, the Mueller matrix of air and of the metal plate has a fine
  pixel-scale pattern (RMS ≈ 0.06–0.07) that is identical in every frame. Its strength depends on the polarization
  channel, so it is most likely real fine structure of the imaged surfaces. A small part (~7%) comes from a residual
  ~0.2 px misalignment between the four analyzer sub-images (Théotim: they are aligned to the nearest pixel). Effect on
  this study: the reference keeps this texture, so strong smoothing is penalized; this is why light parameters win the
  tuning. Parked for now.
- **Scar** acquisition excluded because of drift. **Finger** has small shifts (≤ 3 px, corrected by the registration).
- **One tissue sample** only: the finger result may not generalize. Tuning was done on a plastic card, not tissue.
- **Map metrics** against an averaged reference are biased for low-signal tissue (section 3). `totP_RMSE` can be huge
  (e.g. 35–210 on the Meadowlark card) because of a few pixels where the decomposition is unstable; rely on
  `nM_RMSE_corr` and on the medians.

|---|---|

## 9. Reproduce on your PC (Windows, Anaconda Prompt)

```bat
cd C:\Users\Nihat_AHMADLI\Desktop\SPIE\denoising_mueller
conda activate denoising
git pull
pip install -r requirements.txt
pip install -e .
python -m pytest -q tests
```

Edit `configs\paths.yaml` (Notepad) so it contains exactly:

```yaml
data_root: "C:/Users/Nihat_AHMADLI/Desktop/SPIE/Nihat_data/Measurement_15102026"
calib_root: "C:/Users/Nihat_AHMADLI/Desktop/SPIE/Nihat_data/Measurement_15102026/Calibration"
results_root: "results"
wavelength: 630
```

(The acquisitions are found by name anywhere under `data_root`, so it does not matter which sub-folder they are in.)

Then, from the same folder:

```bat
:: 1. calibration sanity check on the quarter-wave plate (double pass -> 180 deg)
python scripts/check_waveplate.py --acq 2026-10-15_155124_F_FF_HORAO_0000_006 --retardance 180

:: 2. tuning on plastic card 0deg (slow: BM3D ~25 min)
python scripts/compare_levels.py --config configs/compare_levels_oct15.yaml --split val --sweep

:: 3. test with the frozen parameters (finger, card 90deg, Meadowlark; ~30 min)
python scripts/compare_levels.py --config configs/compare_levels_oct15.yaml --split test

:: 4. bias check on the uniform samples (~1 h because of BM3D; add --methods median gaussian nlm wavelet tv to skip it)
python scripts/reference_samples.py --config configs/compare_levels_oct15.yaml --samples configs/reference_samples.yaml

:: 5. clean timing run on one image (close other programs first)
python scripts/compare_levels.py --config configs/compare_levels_oct15.yaml --acq 2026-10-15_154309_F_FF_HORAO_0000_002 --no-figures
```

Each run writes a new time-stamped folder in `results\compare_levels\` or `results\reference_samples\`.
If you change the tuned values, edit the `methods:` block of `configs/compare_levels_oct15.yaml`.

**On the DGX Spark** (Linux): clone the repo, create an environment, copy `Measurement_15102026` over, and run the
same commands with Linux paths in `configs/paths.yaml`. The `bm3d` package may not have a prebuilt version for the
DGX Spark's ARM processor; if `pip install bm3d` fails there, time the other five methods on the DGX Spark and keep
BM3D timed on your PC, stating both machines.

**Housekeeping:** the folder `denoising_mueller\results\_transfer\` on your PC (~540 MB) was only used to copy the
data to the cloud. You can delete it.
